# Inception of Things

## About

Inception of Things is a project from the 42 curriculum focused on containerization, infrastructure and Kubernetes orchestration.

The goal is to deploy and manage applications in containerized environments, from virtual machines to lightweight Kubernetes clusters.

## Key Concepts

- Virtual machine provisioning with Vagrant.
- Containerization with Docker.
- Kubernetes cluster deployment using K3s and K3d.
- Pod, deployment and service management.
- Application configuration and networking.
- GitOps and automated deployment with Argo CD.

## Technologies

- **Infrastructure:** Vagrant, VirtualBox
- **Containerization:** Docker
- **Orchestration:** Kubernetes, K3s, K3d
- **Deployment:** Argo CD
- **Configuration:** YAML, Shell scripting
- **Environment:** Linux
